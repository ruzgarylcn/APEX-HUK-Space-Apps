Pipeline steps

Earth data comes from Google Earth Engine. Use the Project ID from the Google Cloud console, not the project name.

Samples about 190 land cells around western Türkiye, then prints the grid values next to the literature values for Kula and Lake Salda. Takes a few minutes.

Builds the 50 km land grid (about 63 000 cells) and starts 13 Earth Engine tasks that write CSVs to the Drive folder analog_atlas. The tasks keep running on Google's side, so this computer can sleep.

When every task shows COMPLETED, download the analog_atlas_50km_*.csv files from Drive and add them here.

Writes the discoveries for every preset and profile into index.html, so the Atlas still shows them when no server is running.

Open the Atlas with live discoveries
    The local server is not running. Start it by double-clicking start.bat in the project folder (or run python -m uvicorn analog_atlas.server:app --port 8000 in backend), then this page connects by itself.
